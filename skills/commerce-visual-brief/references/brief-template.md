# 最小 brief 参照模板（brief-template）

> **模板 ≠ 校验基线**：校验基线是 `scripts/brief_data.py`（必填字段、词表、
> 映射表）与 `scripts/platform_specs.py`（平台快照）。本模板只是 LLM 层
> 撰写 brief 时的字段命名参照与结构示例，不参与任何退出码判定。
> 按"以平台规范为准，快照会过期"原则，图片规格数值请以目标平台现行规则
> 为准填写。

## 字段参照（与校验基线 REQUIRED_FIELDS 对齐）

```markdown
# 产品视觉 brief

product_name: （产品名，必填）
pricing: （价格与币种，如 ¥399 / $29.90，必填）
size_chart: （尺码/规格表，必填）
color_card: （色卡说明，必填）
category: （品类，如 化妆品 / 母婴 / 家纺——命中词表会触发 V2 声明检查）
locale: （币种 locale，如 zh-cn / ja-jp——与 pricing 币种自洽过 V3）
scene: （拍摄场景设定——与品类过 V5 冲突检查）
```

## 卖点与图位（过 V4 对应检查）

```markdown
卖点: （卖点 1；若引用佐证图，写"见 图N"，且下方图位清单必须存在 图N:）
卖点: （卖点 2；不引用图位也可以，V4 只查"引用了但缺失"）
图1: （图位用途，如 正面白底展示）
图2: （图位用途）
```

## 图片规格声明（--platform 下过 V6–V9；行内需含 主图/图片/规格 等词）

```markdown
主图 800x800 jpg 白底 5 张
```

字段含义：尺寸（像素）、格式、底色要求、张数。未声明的维度校验时保持
沉默（不猜）。

## 平台标记（声明指向特定平台时）

```markdown
淘宝主图 800x800 jpg 白底
```

未核实平台（taobao/tmall/jd/pdd）的条目默认跳过校验；
`--include-unverified` 开启后仅出"未核实、无法校验"标注。

## 提醒

- 极限词（最X/第一/国家级/全网最低/绝对/唯一/根治类）会被 V10 提示；
  比较类措辞（"更耐用 / 较上一代提升"）有反例保护。命中 ≠ 违法，
  是风险提示。
- 写完回到 `python scripts/audit.py validate <brief路径>` 校验（闭环）。
